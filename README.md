# Информационная система «Регистрация и контроль исполнения обращений граждан»

## Назначение

Информационная система предназначена для регистрации, хранения и контроля исполнения обращений граждан.

Приложение позволяет вести тематический классификатор обращений, регистрировать новые обращения, контролировать сроки их исполнения, а также управлять обращениями в зависимости от роли пользователя.

---

## Основные функции для разных ролей

### Гость

- просмотр реестра обращений.

### Пользователь

- авторизация;
- просмотр реестра обращений;
- поиск;
- фильтрация;
- сортировка;
- создание нового обращения.

### Менеджер

- все функции пользователя;
- просмотр списка обращений;
- просмотр состава обращения;
- удаление обращений.

### Администратор

- все функции менеджера;
- редактирование обращений;

## Порядок запуска

### 1. Запустить исполняемый файл .exe

### 2. Авторизоваться(войти как гость)

## Тестовые учётные записи

| Роль | Логин | Пароль |
|------|--------|---------|
| Пользователь | user1 | HASH_USER1 |
| Менеджер | manager1 | HASH_MANAGER1 |
| Менеджер | manager2 | HASH_MANAGER2 |
| Администратор | admin1 | HASH_ADMIN1 |
| Администратор | admin2 | HASH_ADMIN2 |
